# Case selection

First check the project's canonical registry. Do not create a second tracker. Supplied trackers are leads until the user confirms production status. Explicitly selected cases can be developed without requesting selection again.

Score editorially from 1 to 5: central question, source strength, human anchor, discovery/payoff, visual feasibility, distinct angle, and platform suitability. Explain weak points; no arbitrary total or mandatory reversal threshold. Research actual YouTube coverage before calling a case under-covered.

Useful subjects: disappearances, concealed identities, cold cases, staged accounts, mistaken suspicion, exonerations, historical mysteries and digital investigations. Financial cases are optional. Prefer an evidential ending, but an honestly unresolved mystery can work.

Write a short fit test: What is hard to explain? Whom do we follow? What discovery changes our understanding? What can the ending actually answer? If there is a false trail, document its origin and collapse. Do not invent investigative negligence to make the case fit.

Insufficient evidence can block a claim or a long treatment. Active litigation, children's cases and sensitive material need contextual editorial judgment, not automatic import of the old Claude package's exclusions. Never compensate for thin research with graphic detail or speculation.
