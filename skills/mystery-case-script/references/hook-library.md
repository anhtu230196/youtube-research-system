# Hook patterns

Try a few brief openings and choose internally unless the user requests options. Use a verified detail that creates a specific question and earns a later answer.

- A displaced object: why is this item here, and what can it establish?
- An apparent timeline contradiction: state each fact and its evidential status accurately.
- An unexpected institutional connection: suggest the problem without inventing knowledge or revealing an identity central to the mystery.
- An unanswered record: a preserved item or unanswered call with a later role.
- An ordinary action interrupted: use sourced life details, not invented weather or movements.

Avoid greetings, generic shock promises, unsupported superlatives and opening summaries that give away the whole investigation. Title and thumbnail should support the episode's actual question. If the reveal is how evidence proves a known person's role, naming that person can be appropriate; hiding every name is not mandatory.

No worked case example in a writing guide counts as proof of that case. Verify dates, objects, quotations and actions separately.
